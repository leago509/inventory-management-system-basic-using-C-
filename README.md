# inventory-management-system-basic-using-C-
As part of my IBM course, I'm working on a console-based Inventory Management System using C#. The project focuses on fundamental programming concepts, including methods, loops, conditional statements, and inventory operations such as adding products, updating stock, viewing inventory, and removing products.

This project is helping me strengthen my C# programming skills and understand how core software development concepts are applied to practical problems.

Functional Requirements
Add products with a name, price, and stock quantity.
Update stock when products are sold or restocked.
Display all products and their stock levels.
Remove products from inventory.
Provide a menu for users to select operations.
Validate user input to prevent invalid prices and stock quantities.
Non-Functional Requirements
The application should be simple and easy to use.
Stock quantities and prices should be accurate.
The application should display clear error messages.
The program should run in a C# console environment using .NET.
Project Objectives
Develop a working inventory management application.
Allow users to manage products and stock quantities.
Track product prices and availability.
Apply C# programming concepts, including variables, methods, loops, and conditional statements.
Improve reliability through input validatio
